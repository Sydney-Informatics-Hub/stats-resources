[**Stat GPT**](https://statgpt.dialx.ai/)

*Chris says: One of the problems with LLM's like ChatGPT is that they always want to give you what you ask for, even if it's wrong. So if you ask for data it will go find it, and even report it in great looking tables and visualisations, but the data may be wrong and its hard to validate. This is where StatGPT comes in - it only queries respected data sources such as IMF, Eurostat and World Bank, and the ABS.*
